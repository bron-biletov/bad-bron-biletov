В этом проекте нужно с помощью Kilo Code создать робота "Bron Biletov", который сможет бронировать ж/д билеты на сайте https://pass.rw.by/ru/

Речь идёт о таких билетах, которые сложно забронировать самостоятельно, потому что они продаются на популярные рейсы и их быстро раскупают. Но периодически в продажу возвращаются те билеты, от которых отказались.

Робот должен запросить у пользователя данные его учётной записи (логин и пароль), рейс (поезд и время), а также данные пассажира (ФИО, данные документа удостоверяющего личность и номер телефона).

На основе этих данных он должен войти в систему бронирования на сайте https://pass.rw.by/ru/ , найти нужный рейс и проверять с некоторой периодичностью, не появился ли хотя бы один доступный билет.

Как только билет появится, он должен его оперативно забронировать, пока этого не сделал какой-то другой покупатель.
